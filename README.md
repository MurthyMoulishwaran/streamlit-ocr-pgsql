# 📄 Streamlit OCR with PostgreSQL

This project is a **Streamlit web app** that enables users to upload **PDFs or images**, extract text using **Tesseract OCR**, apply **spelling correction** using **SymSpell**, and store the results in a **PostgreSQL** database. It also includes a **search interface** to query stored text based on ID, filename, or page number.

---

## 🚀 Features

- ✅ Upload and extract text from PDFs and images.
- 🔍 OCR using Tesseract with language support.
- 🛠️ Spelling correction using SymSpell.
- 🗃️ Text storage in PostgreSQL.
- 🔎 Search by ID, file name, or page number.
- 💡 Streamlit UI for user-friendly interaction.

---

## 🧰 Technologies Used

- **Python**
- **Streamlit**
- **Tesseract OCR**
- **Poppler for PDF rendering**
- **SymSpellPy**
- **PostgreSQL**
- **Pillow, pdf2image, psycopg2**
